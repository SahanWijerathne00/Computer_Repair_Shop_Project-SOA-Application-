## 📘 About the Project

TechFix specializes in computer repairs, upgrades, and custom PC builds. The business depends on two primary suppliers for hardware and components, but their existing procurement workflow is inefficient.

This SOA-based system addresses these issues by:

- Centralizing supplier communications and pricing.
- Providing real-time inventory insights.
- Automating order placements.
- Exposing services (quoting, inventory, ordering) via APIs.
- Delivering a web and desktop interface for easy access.

---

## 🚀 Key Features

- **Centralized Quoting Platform** – Request and compare supplier quotes within a single interface.
- **Live Inventory Visibility** – View supplier stock in real-time to reduce ordering errors and delays.
- **Automated Order Placement** – Streamlined, error-free ordering through integrated supplier APIs.
- **Data Analytics** – Analyze past purchases and pricing trends with centralized procurement data.
- **Multi-Client Architecture** – Access the platform via a web app or desktop application.
- **Modular Services** – All features are implemented as decoupled services for flexibility and scalability.
